# Tabalyst 0.6.0

Tabalyst 0.6.0 adds Excel workbooks to Inspect, Scan and Report, and relicenses
the code under MPL-2.0. Interfaces and the JSON formats remain experimental
until 1.0.

## Highlights

- `.xlsx` and `.xlsm` workbooks can be inspected, scanned and reported, with the
  `python-calamine` reader. Inspect lists sheets and named tables as candidates,
  with warnings for merged cells, multi-level or duplicate headers.
- `dataset_path` (`$.Sheet` or `$.Sheet.Table`) and `header_row` select the table
  to analyze, in the Inspect file and the configuration.
- `tabalyst report` replaces a stored scan of an older format instead of
  stopping.
- New demo: `examples/input/sales.xlsx` and its outputs.
- The code is licensed under MPL-2.0 and source files carry its header.

## Compatibility

- Profile format revision 11 and scan format revision 6. Scan documents of
  revision 5 are refused and must be scanned again.
- Inspect format: the `excel` kind is added without a revision change.
- New dependency: `python-calamine`.
