# Tabalyst 0.7.7

Tabalyst 0.7.7 adds the `mixed` method to Sample and shows a row progress for every Generate example. It follows 0.7.6.
The commit and the push are done; the tag and the publication are separate steps, kept apart:

| Step | State |
| --- | --- |
| Prepared (code, tests, documentation, this note) | Yes, on `main` |
| Version set in `pyproject.toml` | Yes (0.7.7) |
| Tagged | No |
| Published to PyPI | No |

## Highlights

- **`tabalyst sample --sample-method mixed`.** Keeps `--first-rows` rows from the start, `--last-rows` from the end and
  `--random-rows` drawn among the others, in file order. Each can be 0, at least one must be above 0. No row is kept
  twice: the random rows come from the rows between the two ends. A file shorter than the request is kept whole (100
  rows, 75 first and 75 last give the 100 rows, each once). `--seed` makes the draw reproducible and is an error when
  `--random-rows` is 0 or absent; `--rows` and `--percent` are errors. Two readings of the file.
- **Generate progress.** The examples other than Computer (`insurance`, `crm`) now show a percentage by rows while a
  file is written and while errors are injected, instead of one step per file.

## Compatibility

- No change of format, setting or schema.
- **Python API.** `sample_csv()` and `generate_samples()` gain `first_rows`, `random_rows` and `last_rows`;
  `SampleResult` gains `parts`; `SampleMethod` gains `MIXED`. The `GenerateProgress` events of the non-Computer
  packages count rows instead of files.
