# Tabalyst 0.3.0

Tabalyst 0.3.0 introduces Tabalyst Sample, a streaming CSV sampling tool for
creating smaller representative or targeted datasets without modifying their
sources.

## Highlights

- Added `tabalyst sample INPUT... [OPTIONS]` with `first`, `last`, `random` and
  proportional `stratified` sampling methods.
- Added mutually exclusive `--rows` and `--percent` sample sizes, plus `--seed`
  for reproducible random and stratified selection.
- Added shell-independent, non-recursive wildcard resolution and multi-file
  sampling with `[name].sample.csv` default filenames.
- Added `-o/--output` for one explicit output and `-d/--output-dir` for batch
  destinations, with complete collision and source-overwrite protection.
- Added bounded-memory reservoir sampling, exact proportional stratum
  allocation, source-order output and atomic file replacement.
- Added the public `sample_csv()` and `generate_samples()` Python APIs.
- Added English and French sampling documentation and comprehensive tests for
  methods, proportions, seeds, small and empty strata, encodings, empty inputs
  and invalid requests.

## Format compatibility

The analysis profile remains in format family `0.1.0a`, revision `2`. The
execution-history schema remains `1.0`. Sampling creates CSV output and does not
change either serialized report format.
