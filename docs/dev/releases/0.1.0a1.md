# Tabalyst 0.1.0 Alpha 1

Release date: 2026-09-18

This is the first identified public alpha of Tabalyst. It establishes the initial
CSV-to-JSON-to-HTML workflow and a foundation for rapid, intentionally breaking
experimentation. It is suitable for local evaluation and feedback, not production
workloads.

## Highlights

- Robust CSV ingestion through pandas with configurable encoding and delimiter.
- Reusable analysis service for complete CSV files or individual columns.
- Structured global JSON profile with dataset, quality, type, value, date,
  numeric, normalization, and string-length analysis.
- Custom interactive HTML report with dark and light themes, Bootstrap 5.3.8,
  sortable tables, movable filters, and contextual Clear actions.
- Named output pairs such as `report.html` and `report.json`.
- Persistent `execution.json` history with package version, optional Git state,
  file names, dataset dimensions, and analysis/total execution time.

## Data analysis

- Counts rows, columns, cells, missing values, duplicate rows, empty rows and
  columns, constant columns, and mixed-type columns.
- Infers text, integer, number, boolean, date, mixed, and empty physical types
  with confidence and explicit error rates.
- Detects low-cardinality enum candidates.
- Profiles strict YMD, MDY, and DMY dates with configurable separators,
  ambiguity, invalid calendar dates, and format occurrence counts.
- Applies configurable trim and internal-whitespace normalization while retaining
  detailed change counters and raw preview values.
- Records complete low-cardinality distributions or bounded representative value
  samples for larger columns.
- Classifies text as very short, short, medium, long, or very long; records fixed,
  minimum, maximum, mean, and median lengths; and retains bounded examples by
  observed length through the configured medium threshold.

## Report experience

- Dedicated Columns, Transformations, Numeric summary, Date analysis, String
  analysis, and raw Data sample tables.
- Numeric filters support equality, inclusive ranges, and strict/inclusive upper
  and lower comparisons through one consistent control.
- Type and semantic filters use counted badges.
- Filters can be moved without losing their active state. Clear is shown only
  when the corresponding filter is active.
- Value, date-format, and string-length tooltips expose detailed occurrences
  without overloading the primary tables.

## Formats

- Application version: `0.1.0a1`
- Profile format family: `0.1.0a`
- Profile format revision: `1`
- Execution history schema: `1.0`

The alpha profile format is experimental. Structural and semantic changes may be
incompatible and no migration support is provided yet. Important profile changes
are tracked in the [profile format changelog](../../en/reference/profile-format-changelog.md).

## Validation

- Python 3.11 through 3.14 are declared supported.
- Automated unit, CLI, rendering, malformed-input, and injection-safety tests.
- Automated Edge/Playwright interaction checks at desktop and mobile viewports.
- Ruff static analysis.

## Known limitations

- The complete CSV is loaded into memory.
- Malformed records stop ingestion rather than being repaired or skipped.
- Decimal-comma numbers and semantic patterns such as email and postal codes are
  not yet classified.
- The report depends on CDN assets for Bootstrap, DataTables, and Google Fonts.
- Only the global JSON profile is generated; per-column JSON artifacts and an HTTP
  adapter are planned for later iterations.
- Localization is not implemented yet.

## Upgrade notes

This is the first tracked alpha release. Existing experimental `0.1.0.dev0`
profiles used an earlier unversioned contract and should be regenerated rather
than migrated.
