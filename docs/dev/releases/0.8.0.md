# Tabalyst 0.8.0

Tabalyst 0.8.0 delivers the complete **Generate Insurance V2** engine, transforming the insurance customer generator into an open-source reference benchmark generator for data exploration, quality profiling, sampling strategies and machine learning. It follows 0.7.7.

The code, tests, and documentation are prepared; commit, tag, and publication are separate steps kept apart:

| Step | State |
| --- | --- |
| Prepared (code, tests, documentation, this note) | Yes, on `main` |
| Version set in `pyproject.toml` | Yes (0.8.0) |
| Tagged | No |
| Published to PyPI | No |

## Highlights

- **Verifiable Ground Truth Artifacts.** Every V2 scenario profile automatically produces a complete ground-truth suite alongside the altered CSV:
  - `<dataset>.<profile>.truth.csv`: row-by-row and cell-by-cell truth assertions (`injected`, `net_difference`, `rule_violation`, `valid_atypical`, `relational`, `uncertain`) with canonical clean values, error categories, and detector families.
  - `<dataset>.<profile>.rules.json`: declarative business rules and conventions in JSON format, self-contained and evaluable independently.
  - `<dataset>.<profile>.metrics.json`: exact counts of events, changed cells, net differences, rule violations, and exact hypergeometric absence probabilities.
  - `<dataset>.<profile>.manifest.json`: cryptographic provenance with file sizes, SHA-256 digests, seed, reference date, and scenario definitions.
- **Controlled Rarity Levels & Exact Counts.** Named rarity tiers from `frequent` (5,000 cases) down to `single` (1 case) with exact-count guarantees, accompanied by profile `rare_events` on a minimum floor of 100,000 rows.
- **Output Profiles.** Choose column coverage:
  - `default`: 33 branch columns, 34 combined columns (untouched, bit-identical non-regression).
  - `extended`: 43 branch columns, 44 combined columns (loss dates, coverage caps, deductibles, paid indemnities, acquisition channels, brokers).
  - `complete`: 50 branch columns, 51 combined columns (reimbursement rates, communication consents, manager IDs, customer segments, observation dates, system versions, source systems).
  - `flattened`, `flattened-extended`, `flattened-complete`: denormalized multi-contract projections.
- **Relational In-Memory Population (`--relational`).** Generates a normalized relational database with 4 clean CSV tables (`clients.csv`, `contrats.csv`, `reclamations.csv`, `paiements.csv`) and table-specific ground-truth suites, capturing realistic cardinalities (multi-contract customers, multi-claim policies, shared households, installment disbursements).
- **Sampling Bias & Row Ordering (`--row-order`).** Simulate real-world operational ordering biases: `branch` (E01), `chronological` (E02), `agency` (E03), `shuffled`, or `default`.
- **Missing Data Mechanisms.** Rubin-compliant MCAR, MAR, and MNAR mechanisms with documented missingness reasons (`unreported`, `client_refusal`, `system_omission`, etc.) in profile `missing_mechanisms`.
- **Temporal Drift & System Migrations.** Profile `schema_drift` models historical schema versions (`v1.0`, `v2.0`, `v2.1`), legacy tariff periods, and core IT migrations.
- **Supervised Machine Learning & Fraud Benchmarks.** Isolated ML label files (`<dataset>.<profile>.ml_labels.csv`), leakage-free customer and temporal partitions (`<dataset>.<profile>.splits.csv`), and unobserved generator scores (`<dataset>.<profile>.latent.csv`) in profiles `ml_fraud_imbalanced`, `ml_leakage_test`, and `ml_multitask`.
- **Technical Stress & Edge Cases.** Profile `technical_stress` tests multiline text, complex Unicode, RFC 4180 escaped delimiters, high-cardinality UUIDs, and IEEE 754 precision boundaries; standalone malformed CSVs are isolated in `generate_malformed.py`.
- **Multiple Simultaneous Profiles & Profile Catalog.** Generate multiple profiles in a single command with `--anomaly-profile a,b -d out/`, and discover available profiles via CLI (`--list-profiles`) or Python API (`list_available_anomaly_profiles()`).
- **English Localization & Default CLI Locale (`--locales`, `--english`).** Harmonized with Computer: `tabalyst generate --example insurance` now generates in English by default (`insurance-main.csv`, English column headers, Anglo-Saxon demographics via CommonProvider, Mr./Ms. titles). Generates French with `--locales fr` (`insurance-principal.csv`, French demographics) or both with `--locales en,fr`. Translated file names extend to relational mode (`customers.csv`, `contracts.csv`, `claims.csv`, `payments.csv`). `--english` is retained as a backward-compatible alias.
- **Showcase Demo English-First.** Regenerated public demo `insurance-customers` (100,000 rows with `dirty_stress` defects) and its interactive report in English by default, aligning with Tabalyst's English-first documentation.
- **Evaluation Benchmark Testbed.** Public benchmark suite in `tabalyst-lab` measuring Total Variation Distance (TVD), quantile error, rare recall, and enrichment factors across empirical experiments.

## Compatibility

- **Default non-regression.** All default clean outputs, legacy anomaly profiles (`dirty_realistic`, `dirty_stress`, `rule_breaks`), and showcase demos remain strictly identical byte-for-byte.
- **JSON Schemas.** Added committed schemas in `src/tabalyst/schemas/`:
  - `tabalyst.generate.rules.schema.json` (`0.2.0`, rev 1)
  - `tabalyst.generate.metrics.schema.json` (`0.2.0`, rev 1)
  - `tabalyst.generate.manifest.schema.json` (`0.2.0`, rev 1)
  - `tabalyst.generate.ml_labels.schema.json` (`0.2.0`, rev 1)
  - `tabalyst.generate.splits.schema.json` (`0.2.0`, rev 1)
  - `tabalyst.generate.latent.schema.json` (`0.2.0`, rev 1)
- **Python API.** Exported public functions `build_generate_plan`, `generate_datasets`, `list_available_anomaly_profiles`, `validate_generate_package`, with classes `GeneratePlan`, `ComputerPlan`, `GenerateResult`.
