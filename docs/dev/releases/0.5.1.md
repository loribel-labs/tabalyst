# Tabalyst 0.5.1

Tabalyst 0.5.1 lets `tabalyst report` choose the JSON collection to analyze and
makes the choice easier to write. Interfaces and the JSON formats remain
experimental until 1.0.

## Highlights

- `tabalyst report` gains `--collection`, with the semantics it has in
  `tabalyst scan`: it outranks the Inspect file and the configuration, can be
  repeated, and is refused with `--scan`. `tabalyst.report_service.generate_reports()`
  gains `collections`.
- Short form on both commands: `data.items` is `$.data.items[]` (`[]` is
  implied), `.` is the root array `$[]`, and a key made of digits, such as
  `groups.121`, is accepted as it is. Configuration files and the Python API
  keep absolute paths.
- When several collections are equally plausible, `tabalyst inspect` lists one
  ready-to-run `tabalyst report FILE --collection '<path>'` per eligible
  collection.
- The report theme button cycles auto (the system preference, the new default),
  light and dark.

## Compatibility

- No JSON format changes.
