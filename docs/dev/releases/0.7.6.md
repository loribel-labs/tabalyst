# Tabalyst 0.7.6 (in preparation)

Tabalyst 0.7.6 counts the combinations of missing values of a dataset, names the blocks of columns that go missing
together in the report, and adds the first chart page to `--details`. It follows 0.7.5. This note describes what is on
`main`; the version, the tag and the publication are separate steps, kept apart:

| Step | State |
| --- | --- |
| Prepared (code, tests, documentation, this note) | In progress, on `main` |
| Version set in `pyproject.toml` | No |
| Tagged | No |
| Published to PyPI | No |

## Highlights

- **Combinations of missing values.** The second pass gains `missing_patterns`: for each dataset, the exact set of columns
  each record lacks a value in, counted in the same reading as `missing_matrix`. Never automatic.
- **Blocks in the report.** The *Columns missing together* card of the dataset names the largest groups of columns that go
  missing together and lists the first combinations.
- **Chart pages.** `--details` writes `charts-missing.html` beside the report: an UpSet plot drawn with Apache ECharts and
  the tables of the same figures. The report and the column pages still load nothing from outside.

## Changes of behavior

- **`--details` runs the second pass.** It forces it as `--deep` does: a script that used `--details` outside a terminal on
  a file whose second pass is costly now stops with exit code `3` unless it adds `--yes`. With `deep.mode` `off` in the
  configuration, `--details` is an error.
- **The chart pages load a library from a CDN.** `charts-missing.html` loads Apache ECharts 6.1.0 from jsDelivr, pinned by
  its SRI hash, without a referrer. Offline, its charts show a message and its tables stay.

## Compatibility

- The second-pass document is at revision 5 and the Report profile at revision 6 (`missing_patterns`).
- The new settings `deep.missing.max_patterns` (1,000) and `deep.missing.max_patterns_listed` (200).
- `COST_MODEL_VERSION` 22.
