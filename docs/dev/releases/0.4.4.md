# Tabalyst 0.4.4

Tabalyst 0.4.4 restores fast default CSV scans while retaining scan reuse for
reports. It also adds optional standalone HTML detail pages for each report
column.

## Highlights

- `tabalyst scan data.csv` stores a reusable `scan.json` without building a
  DuckDB database. `tabalyst report data.csv` reuses that document when the
  source and scan settings are current, or atomically replaces it.
- On a local Windows/Python 3.12 benchmark with 20,000 rows and 20 fields,
  the 0.4.3 Scan-plus-DuckDB staging path took 9.47 s; the scan-only command
  took 1.52 s. These measurements are specific to that file and machine.
- `tabalyst report --details` creates one independent HTML page per column,
  linked from the main report. The default report does not create detail pages.

## Compatibility

- Existing 0.4.3 DuckDB project generations are left intact. The private
  project storage API remains available for explicit use, and DuckDB remains
  a package dependency. Ordinary Scan and Report commands do not create a
  database or disposable DuckDB query cache.
- The scan document stays in experimental format family `0.1.0a`, revision 4;
  the report profile stays in revision 9. No format migration is needed.
