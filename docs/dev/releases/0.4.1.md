# Tabalyst 0.4.1

Tabalyst 0.4.1 speeds up Tabalyst Scan on large files, mainly through
adaptive detection on columns with many distinct values, and makes the time
of a report built from a scan document cover the scan.

## Highlights

- Adaptive detection, on by default. The first 10,000 distinct values of each
  field go through every detector; a detector that recognized none of them
  then skips the other values of the field, except about one in 100 (probes).
  Skipped values count as `not_tested`, and a probe that a skipped detector
  recognizes raises a `detector_skipped_reacted` warning. `number` and `date`
  always test every value. Fields with fewer distinct values, and so every
  file under 10,000 rows, are analyzed as before.
- New settings `scan.detection.warmup_values` (default 10,000; `0` restores
  exhaustive detection) and `scan.detection.probe_interval` (default 100;
  `0` disables probes). The report lists them in its analysis settings.
- Faster streaming: field states and duplicate digests look paths up by
  identity, CSV rows are digested from their values alone, detector shape
  checks are memoized and accumulators skip values they ignore.
- `tabalyst report --scan` shows the total time: `processing_seconds`, and
  `analysis_seconds` and `total_seconds` of the execution history, add the
  scan duration recorded in the document.

## Behavior changes

- On fields with more than `warmup_values` distinct values, rare values
  that appear only after the warm-up can go undetected. A sensitive value,
  such as an email address in a comment column, is then not masked. Set
  `scan.detection.warmup_values` to `0` when every value must be tested.

## Format compatibility

The analysis profile remains in format family `0.1.0a` and moves from
revision `6` to revision `7` (new `detection` settings). The scan document
moves from revision `2` to revision `3` (`adaptive` in detector results);
`tabalyst report --scan` reads revision 3 only, so scan older documents
again. The execution-history schema remains `1.0`.
