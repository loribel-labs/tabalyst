# Tabalyst 0.6.2

Tabalyst 0.6.2 introduces Tabalyst Generate, a command for creating synthetic
CSV datasets from a versioned YAML definition. This note describes the release
contents; the commit, tag and publication are separate steps.

## Highlights

- `tabalyst generate` accepts a YAML definition or the packaged `crm` and
  `insurance` examples. It requires an explicit output file or directory.
- The CRM example creates a contacts CSV. Insurance creates three branch CSVs
  and a combined CSV; `--rows` apportions the combined total across branches.
- A selected anomaly profile preserves the clean CSV and adds an altered CSV,
  a cell change log and a JSON summary. The packaged insurance profile targets
  the combined dataset.
- `--seed` and `--as-of-date` override definition defaults. Output paths are
  planned and checked before generation; existing outputs require `--force`.
- The documentation adds a Generate guide and command reference. The existing
  public insurance demo remains a separate dataset.

## Compatibility

- The Generate definition uses experimental `definition_version: 1` and may
  change during beta.
- No Report, Scan or Inspect JSON format change is introduced by Generate.
