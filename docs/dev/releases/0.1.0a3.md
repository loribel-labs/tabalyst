# Tabalyst 0.1.0 Alpha 3

Release date: 2026-09-20

This alpha release redesigns generated reports around faster navigation, clearer
section hierarchy, smoother disclosure controls, and more compact data tables.

## Highlights

- Desktop reports use a sticky left sidebar that groups report and analysis
  sections, including dedicated Data and Settings groups.
- Navigation links show section counts and automatically open collapsed targets.
- At narrow viewport widths, the navigation becomes a compact top section to
  preserve report readability.
- Quality information and Columns are open initially; transformations, numeric,
  date, string, sample, and settings panels are collapsed by default.
- Collapsible panels use aligned animated chevrons, smooth layout expansion, and
  a subtle content reveal while respecting reduced-motion preferences.
- The main content and footer use the full available layout width with the dark
  report palette retained for the canvas and sidebar.
- Reports include an embedded Tabalyst favicon, application version, and GitHub
  repository link.
- Processing time is limited to two decimal places and source sizes switch from
  KB to MB at one mebibyte.
- Analysis tables share a consistent first-column width, compact statistical
  columns, and flexible example or format columns.
- String analysis adds a sortable and filterable Distinct column before Examples.
- Data-sample columns are narrower to reduce horizontal scrolling.

## Formats

- Application version: `0.1.0a3`
- Profile format family: `0.1.0a`
- Profile format revision: `1`
- Execution history schema: `1.0`

The profile format and execution history schema are unchanged from Alpha 2.

## Validation

- Automated rendering coverage confirms sidebar targets, default panel states,
  section counts, and string distinct values.
- The complete Python suite passes with 77 tests.
- Ruff static analysis and JavaScript syntax validation pass.
