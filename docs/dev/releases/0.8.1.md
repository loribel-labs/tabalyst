# Tabalyst 0.8.1

Tabalyst 0.8.1 unifies file naming for the insurance benchmark generator (`insurance-main.csv` across all locales), clarifies bilingual documentation, and updates the public showcase demo to English. It follows 0.8.0.

The code, tests, and documentation are prepared; commit, tag, and publication are separate steps kept apart:

| Step | State |
| --- | --- |
| Prepared (code, tests, documentation, this note) | Yes, on `main` |
| Version set in `pyproject.toml` | Yes (0.8.1) |
| Tagged | No |
| Published to PyPI | No |

## Highlights

- **Unified File Naming (`insurance-main.csv`).** `tabalyst generate --example insurance` now generates `insurance-main.csv` across all single-locale configurations (`--locales en` and `--locales fr`), retiring the former `insurance-principal.csv` name. In multi-locale mode (`--locales en,fr`), files are generated with symmetric names (`insurance-main-en.csv` and `insurance-main-fr.csv`).
- **Bilingual Documentation & Locale Mapping.** The insurance generator documentation (`docs/en/generate/insurance.md`) features a dedicated `Locales and languages` section with explicit console examples for `--locales en`, `--locales fr`, and `--locales en,fr`, an exhaustive column mapping table between French and English headers, and clarified data descriptions.
- **Showcase Demo in English.** Regenerated the public `insurance-customers` demo (100,000 rows with `dirty_stress` anomalies) and its interactive HTML report in English, aligning with Tabalyst's English-first documentation and the updated hero component on `tabalyst.com`.

## Compatibility

- Non-breaking bugfix and documentation release.
- All anomaly injection profiles, ground truth artifacts, and relational mode schemas remain fully compatible.
- Backward compatibility: `--english` alias continues to function as `--locales en`.
