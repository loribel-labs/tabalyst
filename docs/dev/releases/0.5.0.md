# Tabalyst 0.5.0

Tabalyst 0.5.0 adds Tabalyst Inspect and JSON Lines support. Interfaces and the
JSON formats remain experimental until 1.0.

## Highlights

- `tabalyst inspect` reads a `.json`, `.jsonl` or `.ndjson` source, finds its
  collections, proposes the one to analyze and writes `<source>-inspect.json`
  beside the source. Its `config` section sets the collection, the flattening
  of nested objects (separator, depth), the arrays mode and the error policy.
  `tabalyst scan` and `tabalyst report` apply it before any cache or automatic
  detection. `--reset-config` rebuilds the choices; `--force` replaces a file
  that cannot be read.
- When several collections are equally plausible, or none is usable, `scan` and
  `report` stop with exit code `2` and list the candidates, instead of choosing
  one. The Python API gains `tabalyst.inspect()` and
  `tabalyst.generate_inspections()`.
- JSON Lines sources (`.jsonl`, `.ndjson`) can be scanned and reported. A bad
  line is excluded, counted and located by default (`tolerant`, the scan is
  `partial`); `errors.policy: strict` stops at the first one.
- A reusable scan is identified by the full content of the source, the
  effective configuration and the version of Tabalyst. A modification that
  keeps the size and the date is detected, and a new release rescans.
- On Windows, Tabalyst expands wildcards itself, so `tabalyst inspect *.json`
  skips the Inspect files.
- French pages added for installation, the first report and the execution
  history.

## Compatibility

- `tabalyst scan` without `-o` or `-d` stores the scan in the shared storage for
  every format. It no longer writes `<stem>.scan.json` beside a JSON source;
  `-o` and `-d` still export a standalone document.
- A JSON file with a single object or a scalar root no longer produces a `$`
  dataset in `scan` and `report`: Inspect reports that no collection was
  found. `tabalyst.scan()` keeps automatic discovery.
- `report --scan` warns, and does not refuse, when the document comes from
  another version of Tabalyst or when the Inspect file beside the source
  differs.
- Experimental formats, with no migration: scan document revision `5`, report
  profile revision `10` (format family `0.1.0a`) and the new Inspect format,
  revision `1`. Documents written by 0.4.4 must be generated again.
- Not included: Inspect for CSV, array explosion, JSONPath, GeoJSON and
  compressed sources.
