# Tabalyst 0.6.1

Tabalyst 0.6.1 makes the choice of a collection or table from the command line
easier and adds `--all-collections` to `tabalyst report`. Interfaces and the JSON
formats remain experimental until 1.0.

## Highlights

- When several collections of a JSON file or tables of a workbook are equally
  plausible, `report`, `scan` and `inspect` print one command per choice, ready
  to copy and run. `--collection` takes the short form when the name is plain
  (`Costs`, `Sales.Orders`, `data.items`) and the quoted absolute path otherwise
  (`'$["Sales Q1"]'`). The error is the new `UndecidedCollection`, a
  `ConfigurationError`, so exit code `2` and its message are unchanged.
- `tabalyst report --all-collections` reports every visible, eligible collection
  of each JSON file or workbook, one report and one profile per collection, named
  `<name>.<collection-slug>.html` and `.json`. `-d` is optional for one input and
  required for several; it cannot be used with `-o`, `--collection` or `--scan`.
  Hidden sheets are left out with a warning. `tabalyst.generate_reports()` gains
  `all_collections`, and its plan has `warnings`.
- `report` and `scan` warn when an option cannot be used by a source:
  `--delimiter` and `--encoding` outside CSV, `--collection` and
  `--all-collections` on CSV and JSONL. The command still runs.
- The report header shows the "Report" brand suffix, and the report links to the
  documentation and carries the new copyright line.
- Documentation: a page per command in the command line reference and per area
  in the Python API reference, options grouped by file format, `get-started/`
  and `about/` index pages, wrapped output blocks and a code block rule in
  `AGENTS.md`.

## Compatibility

- No JSON format change: profile revision 11, scan revision 6, Inspect revision 1.
- `tabalyst inspect` prints `--collection Costs` instead of `--collection '$.Costs'`
  and says "table" for a workbook.
- Documentation addresses moved: `/install/`, `/examples/` and
  `/report/getting-started/` are now under `/get-started/` (the documentation
  site redirects the old ones).
