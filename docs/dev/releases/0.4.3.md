# Tabalyst 0.4.3

Tabalyst 0.4.3 is the first beta release. Interfaces and the JSON formats
remain experimental until 1.0.

## Highlights

- `tabalyst scan` stores the current CSV scan in a local project generation by
  default. `tabalyst report` reuses that scan when its source and settings are
  current, or publishes a replacement generation.
- `tabalyst cache info` and `tabalyst cache clean` inspect and remove owned,
  disposable query caches without removing the current scan.
- The English documentation and documentation site describe Tabalyst as beta.

## Format compatibility

The report profile keeps experimental format family `0.1.0a`, revision `8`;
the scan document keeps revision `4`. No migration support is provided yet.

## Documentation

The French source pages remain to be updated for the beta release. The
documentation site's status banner is beta in both languages.
