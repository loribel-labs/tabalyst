# Tabalyst 0.1.0

Tabalyst 0.1.0 is the first packaged public-library release.

## Highlights

- Public `tabalyst.analyze()` API returning a JSON-serializable dictionary.
- Direct `tabalyst CSV_PATH REPORT_PATH` command with matching Python module use.
- Named sibling HTML and JSON reports plus cumulative `executions.json` history.
- Strict report-path, separator, encoding, and JSON-configuration validation.
- Public exception hierarchy and metadata-backed `tabalyst.__version__`.
- Wheel and source builds with embedded templates, CSS, and JavaScript.
- Python 3.11 through 3.14 CI and an installed-wheel smoke test.
- PyPI Trusted Publishing workflow with a protected `pypi` environment.
- Reproducible basic and synthetic insurance examples with matching report files.

## Compatibility

The alpha `analyze` and `render` subcommands remain available. Existing low-level
analysis imports also remain accessible for the transition, but the supported
0.1.0 integration boundary is `tabalyst.analyze()`.

The profile format remains `0.1.0a`, revision `1`. The execution-history schema
remains `1.0`; its filename is now `executions.json`.

## Publication status

Tabalyst 0.1.0 is published on PyPI. It validated the complete Trusted Publishing
workflow from the version tag through the protected GitHub environment.
