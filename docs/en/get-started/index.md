---
title: Get started with Tabalyst
description: Install Tabalyst, create a first report from a file of your own and browse finished examples, in three short steps.
---

Tabalyst turns a CSV, JSON, JSON Lines or Excel file into an interactive HTML
report and a JSON profile, on your computer. Three steps take you from nothing
to a report:

1. [Install Tabalyst](install.md), on Windows, macOS or Linux, and
   [keep it up to date](install.md#keep-tabalyst-up-to-date).
2. [Create your first report](first-report.md) with a file of your own, step by
   step.
3. [Browse the examples and demos](examples.md): finished reports for CSV,
   JSON, JSONL and Excel files, with the commands that made them.

Then pick the tool you need: [Tabalyst Report](../report/index.md) for reports,
[Tabalyst Inspect](../inspect/index.md) to choose what is analyzed in a JSON or
Excel file, [Tabalyst Scan](../scan/index.md) for the complete JSON description
of a file and [Tabalyst Sample](../sample/index.md) to cut a large CSV file
down. The [command line](../reference/cli/index.md) page lists every command.
