## Report a defect or request a feature

Use the
[GitHub issue tracker](https://github.com/loribel-labs/tabalyst/issues). Include
the Tabalyst version (`tabalyst --version`), your operating system and Python
version, the command you ran and the message you got. Do not attach real
sensitive data: reduce the file with
[Tabalyst Sample](../sample/index.md) or replace its values first.

## Source code

Tabalyst is developed in the open at
[github.com/loribel-labs/tabalyst](https://github.com/loribel-labs/tabalyst).
The package is on [PyPI](https://pypi.org/project/tabalyst/).
