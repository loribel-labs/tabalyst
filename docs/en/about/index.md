Tabalyst is a beta toolkit for understanding unfamiliar structured data. It
analyzes files on your computer, with no telemetry and no remote processing.

- [Concepts](concepts.md): how the toolkit and its tools fit together, from a
  file to a report, and what stays local.
- [Known limitations](limitations.md): what Tabalyst does not do yet during the
  beta.
- [Release notes](releases.md): what changed in each release.
- [Contributing and issues](contributing.md): where to report a defect, ask for
  a feature and find the source code and licenses.
