# Tabalyst 0.1.1

Tabalyst 0.1.1 is a focused report-presentation update.

## Highlights

- Replaced generic sidebar markers with section-specific SVG icons.
- Added distinct-value counts and representative examples to numeric analysis.
- Added distinct-value counts to date analysis immediately before date formats.
- Styled the `(none)` semantic-type filter option as a compact neutral badge.
- Rebuilt the report footer with the current Tabalyst version, an annual
  copyright notice, and links to the official website and GitHub repository.
- Kept sorting and filtering available for every new distinct-value column.
- Extended browser regression coverage for the new report columns and navigation
  icons.

## Compatibility

The public Python API and command-line interface are unchanged. The profile format
remains `0.1.0a`, revision `1`, because the new report cells reuse existing
`distinct_count` and `value_profile` data. The execution-history schema remains
`1.0`.
