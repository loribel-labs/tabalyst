# Tabalyst 0.1.2

Tabalyst 0.1.2 refreshes the generated report and moves report-facing semantics
into the JSON profile.

## Highlights

- Ported the Signature v1 design into the self-contained HTML report with
  responsive navigation, panels, tables, filtering, sorting, and print styles.
- Added report-facing dataset and column aggregates to the JSON profile so the
  HTML layer can remain focused on presentation.
- Defined `with_issues` as columns containing missing values or inferred as
  `mixed`, and exposed the status directly in JSON.
- Added ambiguous-date reporting, date and inferred-type aggregates, numeric
  ranges, and formatted string-length values.
- Restored percentage labels to the left and occurrence counts to the right.
- Extended row hover styling to the sticky `Column` cell and linked both
  Tabalyst logos to the official website.
- Reworked automated regression coverage for the new report at desktop and
  mobile sizes.

## Compatibility

The public Python API and command-line interface are unchanged. The profile
format remains `0.1.0a` and advances to revision `2` for the additive
report-facing fields. The execution-history schema remains `1.0`.
