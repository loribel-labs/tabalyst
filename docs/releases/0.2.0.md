# Tabalyst 0.2.0

Tabalyst 0.2.0 introduces the command-oriented toolkit foundation and makes
Tabalyst Report practical for both individual CSV files and batches.

## Highlights

- Replaced the transitional CLI with the explicit
  `tabalyst report INPUT... [OPTIONS]` command.
- Added automatic report names based on each source stem, so
  `tabalyst report customers.csv` creates `customers.html` and
  `customers.json` beside the source.
- Added multiple positional inputs and shell-independent, non-recursive glob
  resolution, including `tabalyst report *.csv` on PowerShell.
- Added `-d/--output-dir` for batch destinations while keeping `-o/--output`
  strictly reserved for one explicitly named report.
- Added complete preflight validation for collisions, source/output conflicts,
  and existing artifacts before any batch work begins.
- Added sequential batch continuation after individual CSV failures, with
  aggregated success/failure status and non-zero exit codes.
- Added presentation-neutral progress events and interactive file/phase progress
  on standard error, with `--no-progress` and `--quiet` controls.
- Added the public `generate_reports()` Python API for report planning and batch
  execution without the CLI.
- Repositioned the public documentation around Tabalyst as the platform,
  Tabalyst Report as the tool, and Tabalyst CSV Report as the currently
  available implementation.

## Breaking changes

- The supported CLI now begins with an operation such as `report`. The former
  `tabalyst INPUT OUTPUT`, `tabalyst analyze`, and `tabalyst render` syntaxes are
  no longer available.
- `-o/--output` accepts one input only. Use `-d/--output-dir` for a shared batch
  destination.
- Existing report artifacts are protected by default and require `--force` or
  `force=True` for replacement.
- Success messages and diagnostics are written to standard error so standard
  output remains available for future data streams.

## Upgrade examples

```console
# 0.1.x
tabalyst customers.csv reports/customers.html

# 0.2.0
tabalyst report customers.csv -o reports/customers.html
```

New automatic and batch forms:

```console
tabalyst report customers.csv
tabalyst report *.csv -d reports
```

## Format compatibility

The analysis profile remains in format family `0.1.0a`, revision `2`. The
execution-history schema remains `1.0`. This release changes orchestration and
public interfaces without changing the serialized analysis schema.
