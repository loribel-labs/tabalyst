# Tabalyst 0.1.0 Alpha 2

Release date: 2026-09-19

This alpha release makes generated reports easier to identify and trace to their
source code.

## Highlights

- The report footer now shows the Tabalyst application version used for rendering.
- The footer includes a link to the [Tabalyst GitHub repository](https://github.com/loribel-labs/tabalyst).

## Formats

- Application version: `0.1.0a2`
- Profile format family: `0.1.0a`
- Profile format revision: `1`
- Execution history schema: `1.0`

The profile format and execution history schema are unchanged from Alpha 1.

## Validation

- Automated rendering coverage confirms the footer contains the application
  version and repository link.
- Ruff static analysis passes.
