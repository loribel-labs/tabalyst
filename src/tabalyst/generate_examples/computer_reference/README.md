# Computer brainstorm CSV transcription

These CSV files reproduce tables explicitly written in the private Computer
brainstorm. They are reference material, not a runnable Generate package.
Values and product specifications are illustrative and have not been
verified against manufacturers. No missing values or relations were invented.
The six Laptop GPU rows explicitly appended at source lines 1645–1650
are included in `gpu_model.csv`; the stated `500gb` correction at line 1487
is included in `storage_capacity.csv`.

The executable development package remains in `../computer/`. It still uses
its original two-branch fictional fixture until complete generation,
physical specification, and compatibility data are supplied.
The precise gaps are listed in [MISSING-DATA.md](MISSING-DATA.md).
